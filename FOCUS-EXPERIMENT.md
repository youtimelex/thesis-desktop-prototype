# Thesis: эксперимент без вкладок

Отдельный десктопный вариант на основе `mvp0-desktop-vini-tabs-experiment`.
Он не меняет исходный проект или мобильный прототип. У этого эксперимента отдельный
каталог `node_modules`; перед обновлением VINi всё равно проверяйте план обновления
и принадлежность каталога этому проекту.

## Запуск

В этой папке выполните `npm run dev` и откройте <http://127.0.0.1:4192/>.
Порт задан строго: при занятости сервер завершится, а не переключится на другой порт.
Браузерное хранилище привязано к адресу и порту, поэтому данные 4191 сюда
автоматически не переносятся. Существующее хранилище не очищается и не копируется.

## Что проверять

Открыть запись из общего списка, пространства, поиска и диалога; переключиться
между записями и вернуться на исходную страницу. Проверить сохранение поиска,
фильтров, прокрутки и фокуса; прямую ссылку; список записей и свойства в широком
и узком окне; вкладки материалов и проигрыватель. Повторить в светлой и тёмной
темах. Панель списка не предлагается, если нельзя надёжно определить исходную
подборку (в частности, при переходе из глобального диалога или с главной).

Для изолированной проверки можно открыть `/?preview=1` — изменения данных
прототипа остаются в памяти. Подготовленные браузерные сценарии запускаются при
работающем сервере командой `npx playwright test -c tests/focus-navigation.config.ts`.
Старые тесты проекта могут содержать другие порты и фикстуры; не запускайте их
без предварительной проверки. Аудио и видео, как и прежде, имитируются.

## Обновление VINi

Проектная конфигурация VINi находится в `.codex/config.toml` этой папки. Чтобы
проверить её в Codex, откройте эту папку как доверенный корень локального проекта
и в его чате прочитайте `vini://runtime/connection`: `projectRoot` должен совпадать
с этой папкой. Подключение чата из родительского каталога может указывать на
другой эксперимент; отдельная проверка через VINi local не подтверждает его.

Для выбранной версии сначала изучите план штатного CLI. Обновление проверяет
проект, сохраняет резервную копию и переустанавливает зависимости в этом
эксперименте. После него отдельно проверьте установленные пакеты, перезапущенный
сервер на 4192 и соединение MCP в используемом клиенте. Не меняйте глобальную
конфигурацию и другие варианты ради переключения этого проекта.
