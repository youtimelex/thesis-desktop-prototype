# Thesis — десктопный прототип

Начните с [HANDOFF.md](HANDOFF.md): описание продукта, навигации, архитектуры, данных и сценариев, инструкции запуска и проверки. Это вариант без рабочих вкладок; интеграции имитируются.

Актуальный прототип: https://thesis-desktop-demo.layero.app/?preview=1

Для запуска: Node.js 24, `npm ci`, затем `npm run dev`; откройте http://127.0.0.1:4192/?preview=1. Данные preview остаются в памяти.
